## 📖 项目简介

**轻匣 (SnapBox)** 是一款专为开发者、财务人员和日常办公打造的高颜值、轻量化在线工具箱。无需安装笨重软件，所有工具均在浏览器客户端**纯本地运行**，杜绝数据上传与网络泄露风险，提供快速流畅的操作体验。

---

## ✨ 核心特性

| 工具模块 | 核心能力说明 |
| :--- | :--- |
| **🔄 XML 转义 & 格式化** | 支持 HTML/XML 实体编码互转与树状缩进格式化，解决接口联调转义字符阅读难点 |
| **📋 JSON 解析 & 格式化** | 快速校验语法、色彩高亮排版、智能递归解析多重转义的 String 嵌套 JSON、支持 `{}` 与 `[]` 多层级交互展开/收起、全局展开收起、单行压缩及树/纯文本双模切换 |
| **🔤 命名风格转换** | 一键切换驼峰命名（camelCase）、下划线（snake_case）、大写常量（UPPER_CASE）与短横线（kebab-case） |
| **💴 金额中文大写转换** | 标准规范的阿拉伯数字金额转中文繁体大写（支持角、分、整及零头智能处理） |
| **🗜️ 智能图片极限压缩** | 纯客户端 Canvas 智能压制，支持自定义目标体积上限（KB）、原图/压缩图即时双图比对与下载 |
| **🔐 国密 SM2 加解密** | 支持 SM2 密钥对生成、公钥加密、私钥解密，兼容 04 原始公钥前缀与 C1C3C2 / C1C2C3 密文排列 |
| **🏗️ 数据库 DDL 代码生成** | 智能解析建表 SQL，一键生成规范的 Java 实体类、Mapper、Service 及 ServiceImpl，支持多文件 Tab 预览、单文件复制下载与 ZIP 一键打包 |
| **📄 PDF 智能合并与压缩** | 纯前端本地合并多份 PDF 文档，支持拖拽添加与自由调整合并顺序；支持指定目标体积上限（MB/KB）自适应逼近极限压缩、纯合并无损模式与预设压缩，提供实时进度、体积节省对比、新标签页预览及一键下载 |
| **🚀 更多实用工具** | 持续扩展规划中，涵盖更多高效开发辅助与日常办公实用工具，敬请期待... |

## 🛡️ 核心优势

1. **隐私至上（100% 离线安全）**
   - 不依赖任何第三方服务端中转，所有文本解析、图片压缩和加解密计算均在**浏览器本地完成**，断网亦可全功能使用。
2. **轻装上阵（零外部安装成本）**
   - 单文件 HTML 原生架构，双击即可直接在浏览器运行，没有冗余的环境配置门槛。
3. **现代精致视觉体验**
   - 遵循现代清新美学规范，精心调配的色彩、圆角与微交互动效，并提供桌面端与移动端完美自适应布局。

## 🚀 快速使用

### 方式一：免安装直接打开（推荐）
直接用任一现代浏览器双击打开根目录下的 [`index.html`](./index.html) 即可立即使用。

### 方式二：本地服务调试
如需通过本地 HTTP 服务访问（支持热刷新）：

```bash
# 启动本地服务并自动调起浏览器
npm run dev
```

> 服务默认运行在 `http://localhost:5173`。
